# Claude Code Writes 90% Of Its Own Code As Anthropic Drops Human Mental Models

Coinpedia · Anjali Belgaumkar · 2026-10-29

Claude Code Writes 90% Of Its Own Code As Anthropic Drops Human Mental Models
Anthropic has revealed that Claude now writes about 90% of the code behind Claude Code, its AI coding tool, and that no one on the team holds a full picture of how the system works. Engineers instead ask Claude to produce short explainers for whatever part of the codebase they need. The disclosure came in a blog post on how the team handles code review after daily merged changes in its monorepo rose from about 2,500 in May to over 30,000 in September. Anthropic aims for most pull requests to merge with at most one human involved. Critics on Hacker News warned this leaves no one able to debug a serious failure without the AI. The post also admitted one agent-written pull request ran through more than 50 review rounds overnight before being stopped.
