# ∼21 BILLION tokens per weekly limit on the Max 20x Claude Code usage

Reddit · Glittering_Poem_4755 · 2026-10-13

PURELY on Opus 5.5, after a week of stress testing, at 95% weekly limit, I got 21.4 Billion tokens of usage (the terminal tool ccusage which tends to be more in-depth also agrees on this). Codex $200 plan on 6 Astra only gets between 300 to 800 million tokens, even less after the usage updates. I understand tokens isn't the best way to measure usage, as more token efficient models use less tokens, but on Claude, I've been able to get significantly more test done, as well as better general performance.
