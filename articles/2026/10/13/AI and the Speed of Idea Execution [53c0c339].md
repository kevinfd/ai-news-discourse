# AI and the Speed of Idea Execution.

Reddit · New-Landscape6002 · 2026-10-13

I've been programming since the 1980s, and one of the biggest changes AI has made for me isn't that it writes code faster. It's that I can now afford to explore ideas that I wouldn't have bothered with before. I'm working on a tool to validate and repair Apple II disk images. It started as a simple batch utility. As I worked on it, I kept coming up with ideas for additional features, ways to improve the design, and approaches I wouldn't have considered worth the development time before. One example: I replaced an implementation that used an external Apple II emulator with one that integrates the emulator directly into the application. Processing a couple hundred disks had gone from 7+ hours to less than 30 minutes with parallel processing. That wasn't in the original plan. It became worth doing because the cost of getting there had changed. The other big change is that I'm spending less time translating decisions into code and more time making those decisions. I can try an approach, discover it's wrong, and change direction without feeling I've thrown away weeks of work. AI hasn't eliminated the need for engineering judgment. If anything, that judgment has become more important. I wrote about this in the third post in my AI series. I'd be interested in hearing from you: Has AI changed the kinds of projects or ideas you're willing to pursue, or is it mainly making you faster at doing the same work? https://norsewanderer.com/blog/BlogAI3.html
