# When a chat finally gets it right, ask it to write the prompt that would have gotten there in one message

Reddit · Ok_Negotiation_2587 · 2026-10-13

Most good results take ten messages of back and forth. The tone was off, it missed a constraint, you added an example, it finally clicked. Then next week you need the same thing and you start the whole dance again from zero. So before closing a chat that worked, I send this: This conversation finally got to what I wanted. Write the single prompt I should have sent at the start to get this result in one reply. Include the context, constraints and format we only figured out along the way. Put anything that will change next time in {{double_braces}}, like {{client}} or {{topic}}. Then list the questions you'd still need to ask me if I used this prompt cold. What comes back is usually better than anything I'd write myself, because it's built from the exact corrections I had to make. The last part matters most. Those questions tell you what's still missing, so you can add it now instead of discovering it next time. I keep those as saved prompts in AI Toolbox, the extension I build. The {{ }} parts become blanks you fill in, and typing // in the message box drops the prompt in. Two saved prompts are free. Premium is unlimited and shares one library across ChatGPT, Claude, Gemini and Grok. https://preview.redd.it/plj0xjw549vh1.png?width=1670&format=png&auto=webp&s=9306caf9441efe9b7bd5ba18ca0159d0c82b788e Even without any extension, a notes file with five of these beats re-running the ten-message dance every time.
