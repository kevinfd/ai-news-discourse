# I built an AI skill to help you discover what tech skills to learn next, instead of relying on outdated roadmaps

Reddit · jaitanwar · 2026-10-13

Tech field is changing very fast and if you ask general LLM like chatGPT or Claude abut what should I learn now they usually give outdated answers which were important months ago but are outdated/replaced. So here is the skill I made for codex and Claude Code to help you find the best skill according to your domain. GITHUB LINK OF THE SKILL You can just tell Codex/ClaudeCode to import the skill and do /trending-skill-radar to start the conversation with it. Just ask what I should learn and it will ask questions related to it and start its research.
