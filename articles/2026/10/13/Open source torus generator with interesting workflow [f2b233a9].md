# Open source torus generator with interesting workflow

Reddit · Deep_World_4378 · 2026-10-13

As part of the project that I am working on for generating toroidal structures called Tortoise, I have open-sourced a generator recently. I have now updated it with a “phenomenology” mode such that the fractal, smaller versions can be replaced with eyes, heads etc. the lines with arms, snakes etc. and can also be used to generate images. The project involved first creating a fractal torus with Claude in Threejs, after that each of the parameters of the torus were made to control its variations. Post this I added a controlnet+stability image generation for any pose of the torus using StabilityAI api. In this recent iteration I added 3D models like eyes, heads, snakes etc to replace parts of the torus. Generator link Github link Music by Jordan Garner, Pixabay
