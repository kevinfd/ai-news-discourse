# Microsoft Teams Adds GitHub Copilot With New Combined App

TechJuice · Abdul Wasay · 2026-10-24

Microsoft just merged two separate GitHub apps into a single tool inside Teams. The new app brings GitHub Copilot and GitHub Notifications together. As a result, developers can now track code updates and use AI coding help in the same place.
Before this update, Teams users had to switch between two different GitHub apps. One app handled notifications about code changes. The other gave access to GitHub Copilot’s AI coding features. Now, Microsoft rolled both into one app simply called “GitHub.”
The combined app also brings a useful new feature. GitHub Copilot can now read chat and thread history inside Teams conversations. This means Copilot understands the full context of a discussion before giving its response. However, admins must first grant the required permissions for this to work. Users with an eligible GitHub Copilot license can then type @GitHub in any Teams chat to get AI coding help.
Microsoft also set a clear deadline for the switch. The worldwide rollout started in mid-October and should finish by mid-November 2026. The old GitHub app will stop working on November 16, 2026. Until then, it will appear as “GitHub (deprecated)” in Teams. So all users should remove the old version and install the new one before that date. Admins should also update their app settings so the new version reaches all users.
On top of that, Microsoft announced another Teams feature arriving in November. IT admins will soon create default meeting templates for their entire organization. These templates will automatically apply the company’s preferred privacy and security settings to every new meeting. As a result, meeting organizers will no longer need to set up these options manually each time.
However, only organizers with a Teams Premium license can use default meeting templates. Microsoft will make this feature available for Teams and Outlook on desktop, Mac, and web.
