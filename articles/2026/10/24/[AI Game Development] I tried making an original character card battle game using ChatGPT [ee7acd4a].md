# [AI Game Development] I tried making an original character card battle game using ChatGPT

note · Gerasandesu · 2026-10-24

[AI Game Development] I tried making an original character card battle game using ChatGPT
Introduction
Hello, this is gerasandesu.
This time, I utilized ChatGPT to create "Suitopia Card Battle," featuring original characters.
The characters appearing are Fuka Izumi, Anna Markova, Shizuku Shimazaki, and Chihiro Hirahara. I turned these magical warriors, themed after playing card suits, into cards to create a playable game.
Please see the following pixiv link for each character's profile.
Since the previous 3D action game was mainly an experiment in production, I did not release the game itself. This time, I have released it in a format that can be played in a browser so that everyone can actually play it.
It is free and requires no installation. Landscape orientation is recommended for smartphones.
Note that this game is built with HTML, CSS, and JavaScript, and does not use PHP.
In this note, I will introduce the game's content and the difficulties I faced during production.
I have also uploaded a gameplay video to YouTube, so I would be happy if you could watch that as well.
Game Content
"Suitopia Card Battle" is a game where you play against the CPU using three types of cards: Attack, Defense, and Feint.
The basics follow a rock-paper-scissors style triangle. Attack beats Feint, Defense beats Attack, and Feint beats Defense.
Both sides set one card face down from their hand of three, and they are revealed simultaneously. The winner deals 1 damage to the opponent. However, if both play Attack, both take 1 damage. If both play Defense or both play Feint, neither takes damage.
The starting life is 5. You win if you reduce the opponent's life to 0. If you can no longer draw cards from the deck, the winner is decided by remaining life. If both players' life reaches 0 at the same time, or if they have the same life when the deck runs out, it is a draw.
The four characters each have different card compositions. Fuka is a balanced type, Anna is a defensive type, Shizuku is an offensive type, and Chihiro is a feint type.
Unlike regular rock-paper-scissors, the moves you can make depend on the cards you draw. The key to this game is guessing which cards the opponent has left based on the revealed discard pile and thinking about which card to use.
Tools used for creation
This card battle game was created using the following technologies and tools.
- HTML: Screen structure
- CSS: Screen design and size adjustment
- JavaScript: Game progression and controls
- GitHub Pages: Publishing the game
- ChatGPT: Consulting on game ideas, creating assets and code
I mainly used ChatGPT for the following purposes.
- Brainstorming game ideas I came up with
- Creating illustrations of Fuka and the others
- Writing HTML, CSS, and JavaScript code
- Creating BGM and sound effects
In the game design phase, I first came up with a rough draft, and then, while consulting with ChatGPT, I organized the rules and the framework of the game.
What surprised me this time was that when I explained the movements I wanted to create in detail, ChatGPT generated code that was very much in line with my intentions.
I usually work with languages close to hardware, such as Assembler, so I don't have much knowledge of Web development. Even so, by running the generated code and telling it about the points I was concerned about to make corrections, I was able to proceed to publication.
Difficulties encountered
Just like with the 3D action game last time, I started development thinking it would take about 10 days. However, the code generated by ChatGPT worked almost exactly as intended, and I was able to proceed with development smoothly on my local computer.
I thought it would be finished once I uploaded the code to my personal GitHub account and published it on GitHub Pages.
However, when I checked it on computers, tablets, and smartphones, the layout broke depending on the screen size. Buttons overlapped with images, and the card confirmation screen didn't fit within the screen, so the appearance differed depending on the device.
I reviewed the CSS while consulting with ChatGPT and adjusted the image sizes and button placements to get it into a playable state. This screen adjustment alone took about 3 hours.
For someone like me with no web development experience, making the game display easily across different devices was more difficult than getting the game to run.
Summary
This time, I worked on everything from game production to release, using a card battle theme.
It took about 3 hours to create the game concept and about 15 hours to produce the game. It took shape faster than I expected, and I am the most surprised by what I made.
When I actually played it, I felt it became a more enjoyable game than I had imagined. On the other hand, since the current CPU randomly chooses one card from three in its hand, I felt that there is a large element of luck involved.
In the future, I hope to adjust whether the CPU prioritizes attacking, defending, or feinting depending on the character it uses, and bring out their individual personalities.
Furthermore, I am thinking of having characters from the enemy organization of Fuka and her friends appear, and creating a story mode.
First of all, I would be happy if you could play the current game and give me your feedback. I would like to introduce it again when I have made improvements.
Thank you for reading until the end.
