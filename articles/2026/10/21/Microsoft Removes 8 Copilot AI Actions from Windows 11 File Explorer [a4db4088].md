# Microsoft Removes 8 Copilot AI Actions from Windows 11 File Explorer

Analytics Insight · Somatirtha, Manisha Sharma · 2026-10-21

News
Microsoft Removes 8 Copilot AI Actions from Windows 11 File Explorer
Microsoft is removing eight Copilot AI actions from Windows 11 File Explorer amid backlash over excessive AI integration. The features will remain accessible through other entry points, with the rollout expected to finish in December 2026.
Microsoft is scaling back its Copilot integration in Windows 11, announcing plans to remove eight AI-powered actions from File Explorer’s right-click menu. The move comes amid growing criticism of the company’s expanding use of artificial intelligence across its software, with some users describing the trend as ‘Microslop’.
The company has described the change as an effort to simplify Copilot usage and give users greater control over the options displayed in File Explorer.
Microsoft’s announcement states that eight OneDrive-related Copilot actions will be retired from File Explorer’s context menu. These include Summarize, Create FAQ, Compare Files, Ask a question, Explain image, Explain images, Compare images, and Extract text.
The options appeared when users worked with OneDrive files through File Explorer. Their removal means users will no longer find these individual actions in the right-click menu.
However, Microsoft is not discontinuing the underlying Copilot capabilities. Users will continue to access them through other entry points within Windows and OneDrive.

Windows Latest noted that Microsoft will begin the removal in mid-November 2026 and proceed gradually. Microsoft expects to complete the rollout by early December 2026.
Since the change is being introduced in stages, some users may see the existing options for several weeks before they disappear completely.
The change is part of Microsoft’s broader effort to reconsider how Copilot appears across its products, following criticism of AI features being added to applications where users may not need them.
Although the eight actions are being removed from the context menu, users will still have access to Copilot through other routes.
Microsoft said users can continue working with Copilot by right-clicking a file and selecting ‘Ask Copilot’. The feature will also remain accessible through the File Explorer Home interface and the OneDrive activity center.
The decision follows Microsoft’s March 2026 commitment to integrate AI where it is ‘most meaningful’. Since then, the company has updated Copilot integrations in several applications, including Snipping Tool and Notepad.
For Windows 11 users, the latest change means a less crowded right-click menu without losing access to the underlying AI features. Microsoft is retaining Copilot functionality while reducing the number of separate entry points in File Explorer.
