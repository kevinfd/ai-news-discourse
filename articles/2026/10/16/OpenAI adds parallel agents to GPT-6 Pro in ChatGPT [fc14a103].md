# OpenAI adds parallel agents to GPT-6 Pro in ChatGPT

RuntimeWire · ryanmerket · 2026-10-16

OpenAI adds parallel agents to GPT-6 Pro in ChatGPT
The Chat tab rollout lets Pro users track delegated tasks, but OpenAI's post gives no latency figures or examples to support its claims that GPT-6 Pro responds faster and uses plugins and tools better.
By Ryan Merket · Published
Primary source: X
Why it matters
The Chat tab rollout exposes parallel task delegation in ChatGPT, giving Pro users visibility into agent work. OpenAI has not quantified speed, quality or cost gains or explained how users control tool actions.
OpenAI says GPT-6 Pro can now split tasks among multiple agents in ChatGPT, with the agents working in parallel and showing users their progress. The feature is available to Pro users in the Chat tab, according to the October 16th post.…
