# Meta releases 816B-parameter Muse Spark Open model, runs locally on paired Mac Studios

Valdrans · Valdrans · 2026-10-16

Meta has launched Muse Spark Open, an 816-billion-parameter open-weight AI model with broad platform availability and local Mac Studio support.... Meta described Muse Spark Open as the first model in its class capable of running on a desktop, specifically on two Apple M5 Ultra Mac Studios using Apple's MLX framework. A compressed 4-bit version of the model occupies roughly 493GB, making it too large to fit on a single 512GB Mac Studio.
