Rewriting 98’s Task Manager for $120 in 24 Hours with Claude and Go
Writing system utilities like Task Manager is the best way to test the waters with development tools. These utilities require tight integration with the operating system and make use of various system internal methods. I’ve been testing out Go with Windows for a couple of weeks. TaskMgr98 confronts GitHub Copilot and Claude Fable 5 with new challenges, making it write a Windows native system tool in 24 hours for about $120.
My idea for this project was inspired by Dave W Plummer, the author of the original Task Manager for Windows NT. Nostalgia and a dissatisfaction with the current Windows 11 Task Manager were a factor as well. Recently, Dave also built a modern Task Manager for Windows, macOS and Linux. This further somewhat fueled my curiosity to build the traditional Task Manager on Windows 11 for Arm64 and x64. Not as a remigation, but as an exact Open Source clone of the original from Windows XP.
