# Amp adds Puck and GPT-Live-1 for managing AI agents

Reddit · Codeblix_Ltd · 2026-10-14

OpenAI's October 14 launch post highlights Amp's new work beyond code. It describes Puck, a conversational assistant inside Amp that can start an agent to investigate a bug, coordinate several agents, or find an older technical conversation. Calling Puck uses GPT-Live-1 for real-time voice conversations. The same post says Amp is testing an Ultrafast mode with GPT-6 Astra so users can juggle more agent tasks while waiting less. The practical change is the control layer around the agents: launch them, talk to them, and pick up their work from the same workspace. The source describes the workflow and the product goal, but gives no independent latency or reliability results. This is a launch announcement, not proof that multi-agent work is now dependable. Source: https://openai.com/index/amp-beyond-coding/
