# Can Anthropic stop removing useful features from the Claude Code desktop UI?

Reddit · phatstackzdevops · 2026-10-14

Until this morning, I could simply hover over the context donut in the main window to check context usage. It was quick, convenient, and no extra screen space required. Nothing was broken, and the complaints I've seen on GitHub have overwhelmingly been about restoring easy access to context usage. Now it's been moved to a sidebar that you have to constantly open and close, or leave open permanently. This is especially frustrating for users with vertical monitors, split-screen setups, or narrower windows. Before everyone says "Just use Claude Code CLI," I do. I also use the desktop app, and expecting basic functionality to remain accessible isn't unreasonable. Why not keep the hover and offer the sidebar as an additional option? What's the point? It just adds extra clicks, wastes screen space, and makes functionality objectively worse. I'm not opposed to change. I'm opposed to reductions in functionality disguised as improvement, and changing things just for the sake of changing them without any feedback from actual paying users.
