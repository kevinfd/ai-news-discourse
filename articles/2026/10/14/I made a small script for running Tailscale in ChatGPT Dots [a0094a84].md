# I made a small script for running Tailscale in ChatGPT Dots

Reddit · CH_CGV · 2026-10-14

ChatGPT Dots VMs can be replaced periodically, so I put together a small setup script for running Tailscale with user-level OpenSSH and keeping the installation and node state in `/workspace`. I’ve confirmed it running for over 24 hours in my setup and have now published the project. Feedback would be very welcome: [dots-tailscale v0.1.0]( https://github.com/abruption/dots-tailscale/releases/tag/v0.1.0 ) This is an independent community project, not an official OpenAI or Tailscale tool.
