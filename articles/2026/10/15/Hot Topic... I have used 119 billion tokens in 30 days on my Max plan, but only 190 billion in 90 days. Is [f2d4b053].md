# Hot Topic... I have used 119 billion tokens in 30 days on my Max plan, but only 190 billion in 90 days. Is Opus 5.5 using extra tokens?

Reddit · Shit_Post_Detective · 2026-10-15

I’m curious whether it’s just me. My agent workflows haven’t changed much lately. I’ve run the same setup from Opus 4.6 through 5.0 and now 5.5, usually at high or xhigh effort. Over the last few weeks, though, my token usage has kept climbing. It’s not a huge problem, but it’s noticeable, and I’d like to know whether others are seeing the same thing. I’ve audited my context to rule out bloat on my end. My CLAUDE.md, memory files, and skills are lean, and I’m not loading anything that doesn’t need to be in context. Even so, 5.5 seems to burn noticeably more tokens per task than it used to. Has anyone else seen usage jump?
