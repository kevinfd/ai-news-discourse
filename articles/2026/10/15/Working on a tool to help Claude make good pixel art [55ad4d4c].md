# Working on a tool to help Claude make good pixel art

Reddit · Realistic_Comfort_78 · 2026-10-15

It is a pixel-art DSL with a live viewer. This witch's cottage is 1,000 lines of code. Claude paints with code so I asked it to write a library with all the functionality it usually needs when creating pixel art, so it doesn't have to write all that tooling every time, it is like Aseprite but for Claude. It includes mirroring, auto-outlines, palette swaps, reusable parts, scatter brushes, tilemaps, shadow and light layers, animation frames and lighting. pxl serve opens a live browser viewer that replays every drawing step as Claude saves. You can watch it paint. The scene in the video is one file: the cauldron bubbling, the fire, the candles, the cat and the frog are all animated. Install as a skill: git clone https://github.com/crsolver/claude-pxl ~/.claude/skills/pxl-pixel-art, then ask Claude to draw something
