# Anthropic Claude Code

TIME · Shubham Agarwal · 2026-10-15

Though it started as an internal tool, Claude Code, Anthropic’s autonomous software development platform, now reportedly commands half of the enterprise vibe coding market. That’s probably because Claude Code operates in the auto mode by default, only asking for human approval if it’s about to attempt an irreversible or destructive action. Claude Code Head of Product Cat Wu says this friction-free experience eliminates some of the manual grind traditionally associated with software engineering. “The skills that are becoming more important are the business and product judgement of deciding what we should build,” she says.
Disclosure: Investors in Anthropic include Salesforce, where TIME co-chair and owner Marc Benioff is CEO.
