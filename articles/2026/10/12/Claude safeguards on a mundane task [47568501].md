# Claude safeguards on a mundane task

Reddit · leemcd86 · 2026-10-12

I have recently been using Claude as an assistant to a game (Cataclysm: Dark Days Ahead) and I thought it would be fun to see if Claude could play, as it's turn based it should be able to think before making a move. It decided to install a fresh copy and load the game up in the terminal. I thought no worries, it might be easier for it to read rather than take screenshots. I kept flicking back and forth between the two windows to see what it was thinking and the decisions it was making. I thought it would be better for the thinking to sit alongside the game in the terminal. But when ever I tried to get it to do this i kept getting hit with safeguards and could not get it to tell me why. I even had it tell me what it was doing each step before actioning and it still through up the safeguards. I could only get it working on Haiku. I'm not sure what its blocking, the only thing it mentions is "Details reasoning_extraction"
