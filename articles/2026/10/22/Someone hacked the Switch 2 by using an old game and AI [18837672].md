# Someone hacked the Switch 2 by using an old game and AI

The Verge · Jay Peters · 2026-10-22

The Nintendo Switch 2 has apparently been jailbroken, and a modder has already shown the console running a custom version of Mario Kart World featuring new playable characters like Cinnamoroll, the red Angry Bird, Peter Griffin, and Steve from Minecraft.
Someone hacked the Switch 2 by using an old game and AI
Thanks to a new jailbreak, a modder showed off a custom Mario Kart World featuring Peter Griffin and the red Angry Bird.
OpenAI’s Codex helped make this “ns2jb” jailbreak, according to Sammy Hajhamid, aka “pepsipu.” It’s a software-only, tethered jailbreak, which, in this case, means that you’ll have to run it from a game every time you turn the console on for it to work. This exploit requires the game SmileBASIC 4, which lets users program and play games (though another modder claims that the title is “not strictly needed”).
This jailbreak still seems extremely complex for most people, and its full impact isn’t clear yet; users on the Switch 2 hacks subreddit are debating how big of a deal it actually is. Still, this could mark the beginning of a string of exploits for the Switch 2, especially if modders use AI to help.
