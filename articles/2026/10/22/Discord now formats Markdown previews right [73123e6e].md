# Discord now formats Markdown previews right

The Verge · Jay Peters · 2026-10-22

Discord’s latest update released today has a big improvement for Markdown previews: they should now render correctly instead of with “a bunch of symbols,” according to the company. LLMs and AI agents often rely on Markdown files for instructions and context, so these improved previews could be helpful for people sharing information about AI projects on the platform.
Discord now formats Markdown previews right
Markdown files in Discord now render ‘all nice and neat’ thanks to a new update.
“When you upload a Markdown (.md) file, you’ll now see the file rendered all nice and neat and pretty instead of with a bunch of symbols,” Discord says. “This includes tables, formatting, all that good stuff. Totally great for when you’re doing a casual Sunday-night sharing READMEs with your friends.”
Google has also improved its Markdown support, as it recently started letting users edit Markdown files directly in Docs without having to convert the files to the Docs format.
Discord says its new update also lets you organize servers and channels by right-clicking the icon on the sidebar and using a new “Move to…” feature. Discord Nitro members are also now able to upload files as large as 1GB.
