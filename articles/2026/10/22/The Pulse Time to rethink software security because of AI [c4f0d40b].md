# The Pulse: Time to rethink software security because of AI?

The Pragmatic Engineer · Gergely Orosz · 2026-10-22

The Pulse is a series covering events, insights, and trends within Big Tech and startups.
Today, we cover:
- Time to rethink software security because of AI? A series of high-profile security incidents and breaches took place in a single day, many fueled by AI. Attackers gain advantage by using AI, and defenders will have to respond.
- Is Anthropic’s new version control system “a rip off”? The creator of an open source, high-throughput version control server accuses Anthropic for ripping off their design, and presenting their product as novel by not giving credit to the pre-existing one. It’s not a good look for the leading AI lab.
- Industry Pulse. Saudi Arabia made a “problematic” offer to pay alleged OpenAI spy’s bail, Shopify builds tooling for self-healing software, Foursquare’s sale disappoints, Claude Code gets a major speed boost with gzip, and more.
- Predictions for the future of software development. Some bold calls by software engineer and Amp cofounder Thorsten Ball, such as that open source no longer makes sense.
