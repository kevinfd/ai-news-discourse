# The race to fix huge PHP code flaw at the heart of the internet - The Latest

The Guardian · Presented by Michael Safi with Aisha Down ; producer Angus Neale ; senior producer Leonore Schick ; executive producer Zoe Hitch · 2026-10-22

The race to fix huge PHP code flaw at the heart of the internet - The Latest
Websites around the world have been taken offline as governments and businesses scramble to fix a flaw in the computer language PHP. There are fears that hackers could exploit the vulnerability to steal data, take control of web servers and disrupt services. Millions of attempts have already been made to attack websites since the issue with the programming language was revealed, cybersecurity companies have said.
