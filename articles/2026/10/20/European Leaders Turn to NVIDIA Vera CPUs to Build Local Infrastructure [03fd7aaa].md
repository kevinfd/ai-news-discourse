# European Leaders Turn to NVIDIA Vera CPUs to Build Local Infrastructure

NVIDIA Blog · Hannah Coutand · 2026-10-20

Nebius and Nscale are among global technology partners looking to NVIDIA Vera CPUs to build the next wave of infrastructure.
Their momentum reflects rapid advancements in agentic computing.
Agents do more than generate answers: they retrieve information, run software tools, execute code and evaluate results. Each step depends on fast CPU processing.
Vera accelerates that work, helping agents respond faster and enabling data centers to make better use of computing capacity. Vera is designed to sustain that speed even when running thousands of tasks simultaneously, helping organizations expand services without trading responsiveness for scale.
Building Europe’s Computing Capacity
AI cloud providers Nebius, Nscale and Verda are building with Vera to support the growing computing needs of businesses and developers. High-performance, energy-efficient CPUs help these providers scale the data processing and software execution behind services, alongside the GPUs running models.
The broader sovereign AI ecosystem also includes Aleria, a sovereign AI infrastructure and platform provider, supporting demand for infrastructure that keeps data and operations under customers’ control.
More Ways to Put Vera to Work
Server manufacturers Bull, Dell Technologies, HPE, Lenovo and Supermicro are building Vera-based systems, giving customers more deployment options for their high-performance computing and AI data centers. Vera can power standalone CPU servers or work alongside NVIDIA GPUs in accelerated systems, supporting different workloads and deployment needs.
Data processing companies ClickHouse, Cloudera, Duck Labs, Elastic, Polars, Redpanda, SAP and Starburst observed strong results on Vera for analytical, extract-transform-and-load and semantic search workloads in early testing. Vera’s per-core performance, LPDDR5X memory bandwidth and NVIDIA Scalable Coherency Fabric help achieve performance gains across the board.
Software and developer-platform companies Atlassian, Inherent and Nous Research are adopting Vera for environments where AI agents work alongside developers and researchers. Atlassian is looking to Vera to accelerate the data processing that builds semantic search indexes for its AI-powered products; Inherent has tested Vera and is looking to adopt it for environments where AI agents work alongside engineers on novel scientific research; and Nous Research uses Vera to authenticate agent identities and validate every action before it executes, keeping deployments secure as agent fleets grow.
Baseten-Blaxel, Daytona, E2B, Modal, Prime Intellect and Vercel provide cloud-based sandboxes, which serve as computers for AI agents, and are building on Vera to power the infrastructure agents depend on to execute code, run tools and test results.
Every agent needs a secure, isolated sandbox that can be provisioned instantly, and because sandboxes spin up millions of times a day, the speed of each individual startup cycle compounds at scale. Vera’s fast per-core performance and high-bandwidth memory make it well suited to this pattern, giving sandbox providers the throughput not only to spin up sandboxes but to run agentic workloads at maximum scale without interruption.
