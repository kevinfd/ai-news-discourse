# Having Windows Outlook access problems? An update might have caused it.

Mashable · Alex Perry · 2026-10-20

Having Windows Outlook access problems? An update might have caused it.
Microsoft may have borked Outlook for some folks with a new Windows update.
Specifically, a Windows Server security update has caused access issues for Outlook on some Exchange Server systems, according to a Microsoft security note (cited by BleepingComputer). This is specifically affecting systems running Windows Server 2019 and later, per Microsoft. As a result, users may not be able to access Outlook, or sent messages might just remain in the Outlook outbox without actually going anywhere.
There is no firm fix for this problem just yet. Microsoft says that the severity of the problem will differ from server to server, with some not encountering any problems at all. In a different post, Microsoft urged users not to uninstall the problematic update, instead offering a workaround:
You May Also Like
- Open an elevated Command Prompt on an Exchange Server
- Enter the following as a command: "reg add "HKLM\SOFTWARE\Microsoft\Rpc" /v EpmapSavedContextCap /t REG_DWORD /d 65536 /f"
- Reboot the server
That should help alleviate the issue until Microsoft offers a long-term fix for it.
