# Microsoft has started distributing an 'AI that builds apps just by talking.' What changes with Copilot Code, and 3 things to try first at work

note · メンサ会員のAi活用塾 · 2026-10-26

Microsoft has started distributing an 'AI that builds apps just by talking.' What changes with Copilot Code, and 3 things to try first at work
Microsoft has started distributing "Copilot Code," an AI that builds apps just by talking to it. Even those without programming knowledge can reportedly create tables, summary screens, and small internal tools. It is currently an early version for select companies. Here is a summary of what is new and what to watch out for, divided into facts and commentary.
What happened
On October 21, 2026, Microsoft announced in a notice for administrators (Message Center MC1519871) that it would begin distributing Copilot Code starting in late October. The target is companies participating in an early access program called "Frontier." Since October 22, major overseas IT media outlets have also reported on the start of the rollout.
According to the official explanation (Microsoft Learn), here is what you can do:
- Describe what you want to build in words to create apps, summary screens (dashboards), internal tools, simple websites, data conversions, and scripts (small programs that automatically perform set tasks)
- Watch the screen as it is being built. You can also revert to a previous state
- With your permission, it can use your Microsoft 365 emails, meetings, documents, and calendar as a basis for building
- Completed apps can be published to a cloud provided by Microsoft and shared with people within the company
- If permitted by an administrator, it can be connected to GitHub (a service for saving and sharing programs)
To use it, you need a paid "Microsoft 365 Copilot" license and a usage limit rule (spending policy) set by your company. The pricing is based on a pay-as-you-go model.

Commentary
From here on is this account's perspective.
The biggest change is who the "builder" is. Until now, to create internal tools, you had to ask someone knowledgeable or study it yourself. With Copilot Code, the person facing the problem can simply ask in words, and it will take shape. Microsoft also explains that "the person closest to the problem can build their own tools for a solution."
Similar tools already exist. Tools like Claude Code or Codex allow AI to write programs. However, these are mainly for developers and are built on the assumption that the user has programming knowledge. Copilot Code is located within the regular Copilot app and can directly use company email and meeting information. This is what makes it different. For example, you might be able to ask, "Create a screen where I can see a list of the people in charge and the deadlines decided in last week's meeting."
Those who will benefit most are people who spend time every week on Excel or manual data aggregation. This applies to general affairs, sales administration, and store management. On the other hand, since it is a tool that uses company data, creating and distributing things arbitrarily can lead to confusion. The sharing scope of created apps and the costs incurred depend on the administrator's settings.
3 things to try first at work
Since it is still an early version, many people cannot use it yet. If you prepare now, you can act immediately once it becomes available.
- Write down one "task you do every week." Example: "Every Monday, calculate the totals by store from the sales table and send them by email."
- Put it into words by describing 'who it is for, what they are looking at, and what kind of screen they want.' You can use the template below.
- Ask your company's IT department if they are in the Frontier program or if they plan to use Copilot Code.
When making requests, it is easier to convey your needs by speaking in longer, conversational sentences. If you want to speak your thoughts and turn them directly into text, voice input tools like Typeless or Aqua Voice are good options.

Points to note
- At this stage, it is an early version (preview) for companies in the Frontier program. Microsoft notes that features and release timing may change.
- A paid Microsoft 365 Copilot license and company spending policy settings are required. You will be charged based on usage.
- Running it on your own computer is restricted at first. It can only be used when permitted by an administrator.
- Connection to GitHub is also restricted at first.
- There is no clear official guidance regarding usage in Japanese or the scope of availability in Japan.
- It is explained that the data visible in the apps you create is limited to the scope that the user is already authorized to see.
