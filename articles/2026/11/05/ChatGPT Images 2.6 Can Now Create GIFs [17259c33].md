# ChatGPT Images 2.6 Can Now Create GIFs

Thurrott.com · Laurent Giret · 2026-11-05

- Laurent Giret
- Nov 05, 2026
- 
    
            
        0        
OpenAI just made a new Image 2.6 model available in ChatGPT and Codex, and it can create images faster with more professional visuals. The new model also lets users create animated GIFs from a single prompt.
According to OpenAI, Image 2.6 can generate images 50% faster than before. Through the API, developers can choose between the faster 2.6 Flare model, which can generate images in six seconds when quality is set to low, and the 2.6 Sunburst model that’s better suited for creating professional visuals.

You can also keep reference images of yourself, pets, and characters ready to reuse in new creations…no need to upload them again.

GIFs probably peaked in popularity a couple of years ago, but ChatGPT making it easy to create GIFs from a simple text prompt or a sketch may help to bring them back to the spotlight. OpenAI touted professional use cases, including creating animated brand mascots and product visuals.
OpenAI said today that more than 4 million images are now created every week across ChatGPT, Codex, and the API. All of these AI-generated images come with an invisible SynthID watermark, so they can be easily detected by tools such as Google’s new AI Content Detector or Apple’s Photos and Image Playground apps.
