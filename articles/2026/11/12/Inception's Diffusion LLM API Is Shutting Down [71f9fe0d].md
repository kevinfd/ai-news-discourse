# Inception's Diffusion LLM API Is Shutting Down

Hacker News · _matthew_ · 2026-11-12

Sad to hear, but I got an email from hello@inceptionlabs.ai announcing the Mercury API that hosts their diffusion models is shutting down. No blog post yet but I assume one is coming. Here is the full email:
```
Hi, We want to share an important update regarding the Mercury API. After careful consideration, we’ve made the decision to wind down the service. The Mercury API will remain fully available through December 28, 2026. After this date, you will no longer have access to the service or any data submitted to the platform. We encourage you to retrieve any necessary data before then. If you have questions or need assistance with the transition, please reply to this email. We’re happy to help. It’s been a privilege building Mercury alongside customers like you. Your feedback and ideas have been invaluable in shaping the platform, and we’re deeply grateful for your support and trust. Warmly,
The Inception Team
``` Also a shorter message on their discord from Yannis Miraoui:
```
Hi everyone, API access to all Mercury models will end on December 28, 2026.
Mercury models will no longer be available from Nov 8 via OpenRouter. Thank you for building with Mercury and for being part of this from the start!
Please contact us if you have any additional questions.
```
