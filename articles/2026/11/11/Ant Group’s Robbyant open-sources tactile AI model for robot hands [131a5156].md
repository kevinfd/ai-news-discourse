# Ant Group’s Robbyant open-sources tactile AI model for robot hands

TechNode · yogthos · 2026-11-11

Ant Group’s robotics unit Robbyant has released model weights and inference code for LingBot-Touch, a model designed to help robot hands use touch to handle objects. It was trained on nearly 5,000 hours of recordings from three types of tactile sensors so that it could work across different hardware.
Robbyant evaluated the model on 26 real-world tasks using two robotic hands. The tests included handling fragile objects and coordinating both hands. [Robbyant]
