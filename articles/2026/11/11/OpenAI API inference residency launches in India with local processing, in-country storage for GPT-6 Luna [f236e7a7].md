# OpenAI API inference residency launches in India with local processing, in-country storage for GPT-6 Luna

Moneycontrol · Shaurya Shubham · 2026-11-11

15
OpenAI has introduced local inference for its API in India, allowing eligible businesses and developers to process supported GPT-6 Luna requests within the country to meet domestic data localisation requirements.
  November 12, 2026 / 15:45 IST  
OpenAI has rolled out local processing and inference for its API in India. The move lets eligible organisations run supported AI workloads without sending requests outside the country. The service is limited to the GPT-6 Luna model at launch and extends the data residency options OpenAI already offers in India. The company says the feature targets sectors such as financial services, where rules on where data is handled decide whether an AI application can be deployed at scale.
How local inference works
Until now, OpenAI’s residency options in India covered where customer data was stored. With this update, both the handling of an API request and the model computation that produces the output happen on servers in India. Supported customer content is also kept within the country. OpenAI says businesses can use this for text-based tasks, including document summaries, drafting replies and analysing information for employees.
According to Nitin Bawankule, Head of Enterprise - India at OpenAI, the need for in-country processing has held back some Indian firms from using AI for critical tasks, and local inference is aimed at removing that barrier.
Availability and supported APIs
Local processing applies only to direct API usage. For now, it supports GPT-6 Luna input and output through the Responses API and the Chat Completions API. Developers need to create a new API project, choose India as the region for both storage and processing, and use the India regional endpoint.
OpenAI’s India push
The launch follows OpenAI for India, an initiative announced earlier this year covering AI infrastructure, enterprise adoption, skills and local partnerships. As part of it, OpenAI tied up with Tata Group to build domestic AI data centre capacity. The company recently made a similar residency capability available for select models on AWS Bedrock. OpenAI offers API inference residency in other markets, with India joining Australia and Japan in the latest round of expansion.
