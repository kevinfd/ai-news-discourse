# Perplexity CEO Aravind Srinivas showcases zombie shooter built using Anthropic's Fable 5.2 AI model

Moneycontrol · MC Tech Desk · 2026-11-11

15
The browser-based game reportedly consumed around 100,000 Perplexity credits and was developed without traditional 3D assets. Srinivas also revealed how the AI agent tested the game
  November 12, 2026 / 11:30 IST  
Perplexity CEO Aravind Srinivas has showcased a browser-based endless zombie shooter developed using Anthropic's Fable 5.2 AI model. The project was built with the help of Perplexity's Teammate AI agent, which reportedly spent several hours developing the game using code rather than relying on pre-existing 3D assets.
Srinivas initially shared the demonstration on X, explaining that he had asked a Teammate agent to work with Fable 5.2 for a few hours to create an endless zombie shooter. The resulting game can be played directly through a web browser at cordon9.pplx.app.
In a subsequent post, Srinivas disclosed that the project consumed approximately 100,000 Perplexity credits. He also suggested that more capable AI models, supported by larger inference budgets, could produce significantly more complex results.
"Imagine what a 10x better model with 100x more inference budget can do, in the next 12 months," Srinivas wrote.
He also provided details about how the AI agent tested the game during development. Responding to a user who asked how Teammate verified whether the game was actually playable, Srinivas said it used Chrome running on a rented cloud GPU.
This suggests that the development process involved more than generating code, with the agent also using a browser environment to check the resulting game.
The demonstration comes as Anthropic continues to expand its AI model capabilities and coding offerings. It also highlights how AI agents could potentially handle multiple stages of application development, from writing code to testing functional outputs, with limited human intervention.
