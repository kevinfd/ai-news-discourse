# ChatGPT is getting a chat-tuned GPT-6.2 Sol, and it can offer to watch for a price drop

Digital Trends · Anvinraj Valiyathara · 2026-11-23

OpenAI has rolled out GPT-6.2 Sol to ChatGPT’s Chat tab, tuned for everyday conversation. This comes less than a week after it announced GPT-6.2 Astra and Sol in ChatGPT Work and Codex. OpenAI’s release notes say the model has been optimized for the Chat tab and is now available to Plus, Pro, Business, and Enterprise users. According to the company, the new model is better at following detailed instructions, reading details in photos, and searching the web.
What changes in the chat you already use?
According to OpenAI, Sol is built for everyday work, while Astra is its frontier model for complex work. The Chat version of Sol can help you weigh hotels by price and location and pick up finer details in photos, such as text or symbols in an image. If you ask whether something is on sale, it can also offer to let you know when the price drops.
In OpenAI’s tests in the Chat tab, it scored 71.7 percent on image understanding, up from 47.4 percent for GPT-6. On especially challenging prompts, it followed instructions 78.1 percent of the time, up from 62.5 percent.
It’s rolling out to paid plans, and GPT-5.6 has a retirement date
GPT-6.2 began rolling out on November 23 to Plus, Pro, Business, and Enterprise users, but Free and Go users aren’t included yet. Enterprise access depends on workplace admin settings. The models powering Work and Codex are not changing as part of this release.
If your model picker shows GPT-6.2, the “Latest” option now uses it across all four thinking modes: Instant, Medium, High, and Extra High. The Pro thinking level still uses GPT-6 Pro, as there’s no GPT-6.2 Pro option yet. If you’re currently using GPT-5.6 Sol, you can keep using it in Chat until OpenAI retires it on December 23, when GPT-5.6 Sol and GPT-5.6 Terra also leave Work and Codex.
