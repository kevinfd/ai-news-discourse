# We made a multiplayer game where each player's view is generated by a world model running on their GPU [P]

Vor · bengal7ion · 2026-11-15

We trained a world model on our open dataset of 10-player CS:GO bot matches (~3,958 hours, with all POVs and inputs aligned at 16 Hz), which we released last month. Now you can actually play it with other people. A lightweight server keeps the game state in sync, while each player runs the model locally to generate their own view based on that state and their inputs. Server states, player actions and previous frames are fed into diffusion transformers to draw the next frame.
