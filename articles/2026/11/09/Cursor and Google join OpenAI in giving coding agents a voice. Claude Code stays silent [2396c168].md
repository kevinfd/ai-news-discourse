# Cursor and Google join OpenAI in giving coding agents a voice. Claude Code stays silent.

The New Stack · Paul Sawers · 2026-11-09

Two of the biggest players in the AI coding space are betting that developers want to talk to their agents while they work, with both announcing a two-way voice feature that lets users ask questions and give follow-up instructions without returning to the keyboard. 

 On Friday , Cursor announced Voice Chat with Agents , a Grok Voice -powered feature that lets developers call an agent and talk through a change. On the very same day, Google announced Voice mode in Antigravity , which uses Gemini Live to bring spoken conversations to its desktop app and command-line tool. 

 In a blog post announcing the feature, Nick Van der Auwermeulen , developer relations engineer at Google, contrasts the back-and-forth dynamic of human colleagues with the “rhythm” of working with coding agents. 

 “Some of the best engineering happens out loud,” Van der Auwermeulen writes. “You talk a bug through with a teammate, think out loud in front of a whiteboard, or say ‘ wait, try it the other way ’ halfway through a pairing session. Working with an agent has mostly had a different rhythm: you type a prompt, the agent works, you read what it did, and you type again.” 

 “Some of the best engineering happens out loud.” 

 The longer a job runs, he adds, the more often developers need to check in. A command might be waiting for approval, or a developer might spot a requirement the original instructions missed. 

 “Each of those moments pulls you back to the keyboard and away from whatever you were looking at,” he continues. 

 And so Antigravity’s voice mode keeps a live call open while the coding agent works, so the developer can hear an update or approve a command without reaching for the keyboard. 

 Cursor, for its part, makes a similar pitch for keeping the conversation going. 

 “Describe a change out loud, ask what an agent is working on, and hear updates as the work moves forward,” the company writes.

 Look who’s talking 

 Antigravity , for the uninitiated, is Google’s agentic software development platform. It debuted alongside Gemini 3 last November , with version 2.0 landing in May replete with a separate desktop app. There’s also a terminal client, Antigravity CLI , and extensions for developers who want to work from editors such as VS Code, JetBrains IDEs and Xcode. 

 Antigravity is now where Google is consolidating its various coding tools, having moved individual Gemini CLI users to Antigravity in June, while it’s also in the midst of sunsetting Jules , a previously launched background coding agent. 

 It’s worth noting that Antigravity’s existing dictation feature already turns speech into a written prompt. Now, to start a two-way call in the desktop app, the user clicks the waveform button beside it and tells the agent what they want it to do. 

 Starting a voice call 

 Antigravity replies aloud and keeps the call open while the coding agent works, with the user able to ask how it’s going or give it further instructions. You can also interrupt the agent mid-sentence to ask a question or give it another instruction. 

 Antigravity responds out loud 

 When the agent finishes, its written summary and a button to review the code changes appear in the same chat. 

 Reviewing the fix mid-call 

 Additionally, voice mode also works in the Antigravity CLI. Users run the /voice live command to start a call, and hear the agent reply while it works away in the terminal. 

 Starting a terminal voice call 

 Coding agents talk back 

 Cursor, which was acquired by Elon Musk’s SpaceX in August for $60 billion, has followed a similar path toward embracing voice. It added dictation in October 2025 , and in release notes last month, the company said it had updated existing voice calls to let agents give short spoken progress updates. 

 One difference with Cursor’s rollout is where you can call from. Cursor supports voice chat on the web and iOS as well as on desktop, while Google offers it in the Antigravity desktop app and CLI. Cursor’s calls run on Grok Voice , which xAI launched through its API back in April . 

 “The push now, it seems, is to keep the conversation going after the agent starts work.” 

 However, Google and Cursor aren’t the first AI companies to bring two-way voice to coding agents. OpenAI launched a Codex desktop app in February with a built-in dictation feature . And as The New Stack reported in July , the company added two-way voice to Codex in the ChatGPT desktop app, letting developers give instructions and check on tasks by speaking. The Codex CLI has offered live voice conversations since the spring , with OpenAI enabling them by default in September . 

 Anthropic, for what it’s worth, has a voice mode which offers two-way voice functionality inside the Claude app only. In Claude Code, specifically, voice still only goes one way via dictation — the /voice command turns developers’ vocal instructions into prompt text , and the agent replies in writing. 

 Dictation itself is useful for describing a bug or sketching out a feature aloud, and it’s showing up across the AI coding landscape, from the major AI labs to well-funded startups such as Replit . 

 The push now, it seems, is to keep the conversation going after the agent starts work, so developers can follow up about a decision, clarify a requirement, or change direction before the work is finished.
