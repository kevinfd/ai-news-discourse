# 'Ram-Altman' Program Will Email OpenAI's CEO About Your Memory Usage

PCMag · Michael Kan · 2026-11-09

A developer is trolling Sam Altman’s controversial comments about the memory shortage by releasing a program that’ll automatically email OpenAI’s CEO when the DRAM on a personal computer is going to waste.
The Linux-based program is called “Ram Altman” and functions as a script that lists commands to check a computer’s RAM usage. It’ll then draft a message to Altman’s known email address, informing him that the computer’s unused memory is available.
“If your machine has more than 10% of its RAM available, it sends one email a day to let Sam know,” says UK-based developer Iain Kay. “It seemed only fair. He can't fix the problem if nobody tells him where the RAM is.”
Last month, Altman suggested that it's a waste of industry resources to create PCs outfitted with large amounts of memory to run AI locally. “Actually, it’s quite terrible to have everybody have a bunch of the world’s limited supply of DRAM sitting in their own computer. And be used 5% of the time,” he said during an appearance on the Cheeky Pint podcast.
Altman’s comments received widespread backlash, partly because OpenAI has been a primary driver for the ongoing memory shortage, which has inflated pricing for PC building and consumer electronics everywhere. In response, Altman engaged in some damage control, claiming his comments were taken out of context. He even briefly changed his profile name on X to “Ram Altman,” while tweeting: “i want you to have so much ram, lets build more.”
However, Kay decided to mock Altman, noting “now someone keeps him informed” about people’s memory usage. “If more than 10% of your RAM is available, Sam gets a note with your real figures. Messages rotate, so the joke gets old at a carefully managed pace,” Kay wrote in a website dedicated to the Ram-Altman program.
The automatically created emails can further poke fun at Altman with messages including: “Please don't be alarmed, but there is 8.6 GiB of RAM on my desk that isn't in a data centre. That's 56.2% of what's installed here, and as far as I can tell it has no plans today. Yours, with memory to spare, a concerned RAM owner.”
