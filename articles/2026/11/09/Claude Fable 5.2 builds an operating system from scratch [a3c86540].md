# Claude Fable 5.2 builds an operating system from scratch

Youtu · GrandCollection7390 · 2026-11-09

As an experiment, one Anthropic engineer gave Fable 5.2 the task of designing a prototype operating system. Starting from an empty folder, the model coordonated over 1,000 subagents, working around the clock for eight days writing, testing and reviewing code. It produced a working operating system that boots on a laptop, with its own core that runs the machine, drivers for the disk, keyboard, network, file storage, login screen, windows and built-in Claude functionality.
