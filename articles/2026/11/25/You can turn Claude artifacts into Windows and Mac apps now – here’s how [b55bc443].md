# You can turn Claude artifacts into Windows and Mac apps now – here’s how

ZDNet · Radhika Rajkumar · 2026-11-25

ZDNET’s key takeaways
- You can install Claude artifacts as desktop apps, but they’ll need Wi-Fi.
- Be careful when giving artifact apps full computer access.
- Claude, a work tool in its own right, is spawning even more work tools.
Anthropic is making its Claude artifacts available as desktop apps, meaning you can share and more easily access your most-repeated tasks on your computer. The “install as app” feature is available in beta for all free and paid Claude plans and works on both Mac and Windows, but not Linux.

Anthropic first released artifacts in 2024. Since then, they’ve become a way to standardize and repeat tasks users do regularly, especially at work. Previously, artifacts ran via your Claude window or in a browser. By splicing them out as distinct desktop apps, you can now run different Claude queries while also using your artifacts locally, or use those apps without opening Claude at all.
More from ZDNET
“When an artifact is installed as a Mac or Windows app, it gets its own icon and opens in its own window instead of inside Claude. You can share it with others, and it needs your permission before it can interact with your computer,” Anthropic said.
Artifact apps can still access Claude and any connectors you’re using, and they update automatically when you edit the artifact itself in Claude. When apps request something from Claude, though, that goes toward your Claude usage limits, which are lowest for free users.
Anthropic said the app feature is meant to streamline building apps for both developer and non-developer work.

The update clarifies where AI software for work is headed. Claude is already more of an AI-powered work suite than a single helpful chatbot for many organizations. Evidently, people are using tools like artifacts frequently enough — and simultaneously with other Claude features — that they need those Claude-based tools to function like discrete bits of software on their own.
“If you rely on a tool for work, it should open like the rest of your apps and remind you when something needs your attention,” Anthropic said.
What are the limitations of Claude artifact apps?
Claude artifact apps don’t have the same functionality as apps you could build using Claude Code, though. Even if you don’t need Claude open for these apps to work, you’ll still need to be signed in to Claude and have internet access, so they’re not an entirely portable or off-grid option.
The feature’s support page also notes that legacy artifacts, “live artifacts from Claude Cowork,” and artifacts generated from templates like Docs, Slides, and Sheets can’t be installed as desktop apps.
How to install Claude artifacts as desktop apps on Mac and Windows
First, make sure Claude for Mac or Windows is updated. You can try the “install as app” feature, which is in beta for all free and paid plans, via Claude’s Share menu. Select the Install as app option, which will then download the artifact you chose to your desktop. From there, set permissions as needed.
- Open the artifact you want to install in Claude.
- Open Claude’s Share menu.
- Select the Install as app option, which will then download the artifact you chose to your desktop.
- Set permissions as needed.
How to manage Claude artifact app permissions
Permissions range from the default (whatever they are in a browser) to app-specific permissions like sending notifications and full computer access.

Full computer access means the artifact app can “run programs and read, change, or delete your files without asking each time,” Anthropic said, so proceed carefully. Every time you edit and update the artifact (and thus the app), Claude will ask you to confirm permissions again, so you’ll ideally have regular checkpoints to revise access. Still, there are some guardrails in place: Anthropic only lets you give full computer access to apps you’ve made yourself. For Team and Enterprise plans, that extends to any apps made by your coworkers.
“Anthropic doesn’t review apps before you install them, so only give full access to apps you trust,” the company said.
For Claude Enterprise plans, the install-as-app feature is off entirely until an admin turns it on in Organization settings.
