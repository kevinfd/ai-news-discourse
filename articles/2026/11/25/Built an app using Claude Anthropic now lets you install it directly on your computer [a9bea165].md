# Built an app using Claude? Anthropic now lets you install it directly on your computer

Mathrubhumi English · Tech Desk · 2026-11-25

Anthropic has introduced a new feature that allows users to turn Claude Artifacts into standalone desktop applications on Mac and Windows computers. The beta feature, called 'Install as app', enables users to create, install and run AI-generated applications outside the Claude interface without packaging software or managing separate API keys.
Anthropic, the company behind the Claude AI assistant, announced the feature on Tuesday, November 24. It is designed to make applications created using Claude easier to install, access and use as part of everyday workflows.
Under the new feature, users can create an Artifact within Claude and install it directly on their computers as an independent application. Once installed, each app gets its own desktop icon and opens in a separate window rather than remaining inside Claude's interface.
The feature is available in beta for Claude users on Mac and Windows across all plans.
What are Claude Artifacts?
Claude Artifacts are interactive creations generated using Anthropic's AI assistant. They can include documents, presentations, dashboards, diagrams and small applications.
Unlike regular responses in a chat, Artifacts appear in a separate side panel alongside the conversation. Users can edit, reuse and share these creations.
Anthropic said Artifacts were initially designed as outputs that users could share with others. However, their use has expanded, with people increasingly creating tools for everyday tasks.
Examples include meeting preparation pages, applications that organise files, performance monitoring tools and image editors.
The new feature allows users to take these creations beyond the Claude interface and use them as desktop applications.
How does the 'Install as app' feature work?
Users can create an application using Claude and install it directly on a Mac or Windows computer.
The installed application gets a separate desktop icon and opens in its own window. Users do not need to package or digitally sign the application themselves.
The apps also use the user's existing Claude account, eliminating the need for a separate login or API key.
Anthropic said installed applications can use Claude and connected services, known as connectors. They also update automatically when the underlying Artifact is edited.
Requests made by these applications to Claude count towards the user's existing plan usage limits.
Installed apps can also send notifications and add items to the Mac menu bar or Windows system tray.
However, users must remain connected to the internet and signed in to Claude to open these applications.
Three levels of permissions explained
One of the important aspects of the feature is the level of access users can grant installed applications.
Anthropic has outlined three permission levels:
1. Default permissions: Applications can access only the capabilities available to them within a web browser.
2. App permissions: Applications can request access to common computer features that Claude can control.
3. Full computer access: Applications can request permission to run programmes and read, modify or delete files on the computer without seeking separate approval for every action.
Anthropic said users can control the level of access granted to individual applications.
Importantly, permissions apply only to the current version of an application. If an app is updated, including through changes made by its creator, Claude will ask users to grant permission again.
What applications can users create?
Anthropic shared examples of applications its own employees have created using the feature.
These include a layered image editor, a file manager, tools for organising folders, a terminal assistant that helps explain commands and an application for monitoring computer performance.
The development is aimed at making it easier for both developers and non-technical users to turn AI-generated tools into applications they can access regularly.
Availability: Who can use the feature?
The 'Install as app' feature is rolling out in beta across all Claude plans for Mac and Windows users.
For Team subscriptions, the feature is enabled by default, although full computer access remains disabled.
For Enterprise subscriptions, the feature is disabled until an organisation's owner enables it. Administrators can also control application permissions and full computer access across their organisation.
However, not every Artifact can be installed. Claude Docs, Slides and Sheets are among the formats that are currently excluded.
What does this mean for AI-powered app development?
Anthropic's latest feature signals a shift in how AI-generated applications can be used. Instead of limiting Claude-created tools to a browser-based interface, the company is making it possible to turn them into desktop applications.
1. Lower barriers to building applications
Users no longer need to package or digitally sign applications themselves. This could make simple software creation more accessible to people without traditional programming experience.
2. AI tools move closer to everyday computer workflows
Standalone applications can be used in separate windows, send notifications and interact with connected services. This could make AI-generated tools more practical for regular tasks rather than occasional experiments.
3. Computer access raises security considerations
The ability to read, modify or delete files and run programmes makes permission management particularly important. Users will need to understand what access an application requires before granting it.
Anthropic's decision to separate default, app-level and full computer permissions provides a framework for controlling that access.
4. A broader shift towards AI-generated software
The feature reflects the growing competition among AI companies to move beyond chatbots and coding assistants towards tools that can build functional software. By allowing Claude Artifacts to operate as desktop applications, Anthropic is expanding the potential uses of its AI assistant.
However, the applications are not completely independent of Claude. They require an internet connection, an active Claude sign-in and usage allowance under the user's subscription.
