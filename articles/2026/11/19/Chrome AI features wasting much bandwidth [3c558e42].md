# Chrome AI features wasting much bandwidth

Perishable Press · speckx · 2026-11-19

Chrome AI Features Wasting Much Bandwidth
🔎 Finally solved the mystery. At some point this year (around a few months ago), my bandwidth/data usage went thru the roof. Figured out it was Chrome’s recent AI features. Then got immediate bandwidth-relief after disabling all the “AI innovations” and “On-device” stuff. Here is a screenshot of the settings:
I simply disabled everything on that settings page, and the needless bandwidth leakage stopped immediately.
Don’t take my word for it. Fire up your favorite activity/network monitor. Watch the network activity while Chrome’s AI features are enabled, which they are by default. Note the continual bandwidth/data spend coming from Chrome, which if you care to monitor long-term adds up to many GBs per month (depending on setup, usage, etc.).
After watching the meter spin for a while, go into the Chrome settings and disable all the “AI innovations” and “On-device” stuff. Then return to the network monitor and watch it virtually flatline. Problem solved.
Commentary
Chrome should have left the AI resource hogs disabled by default. Someone do the math on how much energy and bandwidth is absolutely wasted by all the people (such as myself) who never touch the AI stuff.
Before I disabled the AI settings, Chrome was gobbling endless GBs. Multiply by the number of Chrome users who aren’t using “AI whatever neat”, and you’re talking real numbers. Real waste. For something that serves absolutely no purpose, that’s a ridiculous spend.
That’s all for now, I’m off to try some new browsers. There are quite a few great Chrome-alternatives these days.
