# Launch HN: Onlook (YC W25) – An open-source developer tool for designers

GitHub · D_R_Farrell · 2026-11-19

The developer tool for Designers
    
Onlook is a free, local-first editor where designers craft exceptional experiences in code
    
→ Download today 
  
👨💻👩💻👨💻 We're hiring engineers and designers in SF! 👩💻👨💻👩💻
中文 | Español | Deutsch | français | Português | Русский | 日本語 | 한국어
Craft websites, prototypes, and designs with AI on a canvas built for creative work. See your real app running live, shape it visually, and let your own agent write the code. An open-source alternative to Figma, V0, Replit Agent, Base 44, Webflow, etc.
- 🎨 Built for design. Onlook is the open-source developer tool for designers. You see your real app running live on a canvas, explore ideas side by side, and shape the interface visually instead of from a terminal. Design apps, websites, posters, graphics, and more with your local fonts and assets.
- 🤖 Bring your own agent. We don't ship our own model. Connect the Claude Code or ChatGPT/Codex account you already have, and that agent does the work inside your project. Plug in more tools through MCP connectors to bring all of the context you need to your creative workflow. Work on multiple design tasks at once across repos and pages.
- 📁 Works on your real repo. Onlook opens any Git repository on your machine and runs your own dev server, so what you design is your actual product, not a mockup that someone has to rebuild later.
- 🖥️ A desktop app, local-first. Onlook runs on your computer. Your code stays on your computer, and the source build needs no Onlook account, cloud keys, or .env file.
- 📤 Share what you make. Export artifacts as self-contained HTML, PNG, JPEG, or PDF to hand off, review, or post.
- 🧡 Open source. Apache 2.0. Read it, fork it, and customize it yourself (we'd love to hear how you customize it!)
-  Design on your real codebase
  - Live app on an infinite canvas
  - Mobile, tablet, and desktop frames side by side
  - Safe worktree copy, so your folder is never touched
  - Parallel projects as tabs
-  Design with your own agent
  - Bring your own Claude Code or ChatGPT/Codex plan
  - Ask about any element on the canvas
  - Agent arranges the canvas for you (variations, states, flows)
  - Reference images on the canvas
-  Sketch and share
  - Artifacts for quick HTML sketches outside your repo
  - Export to HTML, PDF, PNG, and JPEG

  - Start entirely new codebases from scratch
  - One-press pull requests, from checks to merge
🖥️ Download the Desktop App (Recommended) – The fastest way to get started with Onlook.
- macOS (Apple Silicon · Intel x64) → Download
- Windows – Coming soon. Join the Windows waitlist here and be emailed when we have updates.
- Linux – No Linux artifact is published and we're still gauging demand for Linux. Join the Linux waitlist here and be emailed when we have updates.
🧑💻 Build from source – SOURCE_BUILD.md covers building and running Onlook on a Mac. No Onlook account or cloud keys needed.
- Open a project. Point Onlook at any Git repository on your computer, or import one. Your code stays where it is.
- Onlook runs your app. It starts your own dev server locally, the same way you would from a terminal.
- See it live on a canvas. Your running app appears in frames on an open canvas, so you can look at pages, sizes, and ideas side by side.
- Design with your agent. Describe what you want in chat. Onlook hands the request to the Claude Code or ChatGPT/Codex account you connected, and that agent edits the real files in your repo.
- Watch it update. Changes show up on the canvas as your dev server reloads, and Git keeps track of everything that changed.
- Share the result. Export artifacts as self-contained HTML, PNG, JPEG, or PDF.
Because Onlook runs your project with its own tooling, it works with all web frameworks or languages your dev server already supports.
- Start a new empty project by clicking the "New Draft" button in the upper left corner of the projects page.
- Use the input box in the lower right corner of the screen to write what you'd like to be designed in Onlook.
- Answer clarifying questions from the agent, and wait for it to build
- Click to select individual frames for context in follow-up prompts, or double-click on a specific element to use the inline chat and guide the AI to edit that specific element.
- Prompt more ideas on one or multiple designs until you're ready to share your work with a colleague.
- Select the frame you'd like to share, and ask the agent to convert it into an Artifact for exporting.
- Export the artifact as HTML/CSS or as a PNG using the export button in the upper right corner of the frame.
- Paste the exported artifact in Slack, email, or any messaging tool.
