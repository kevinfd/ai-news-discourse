# DeepSeek Harness new Creator Mode creates plugins from prompts

Mashable · Amanda Yeo · 2026-11-03

DeepSeek Harness' new Creator Mode creates plugins from prompts
DeepSeek Harness has added a new Creator Mode, which aims to create plugins directly from text prompts.
While AI models are capable of generating responses to prompts and determining a course of action, actually carrying it out requires a harness. Harnesses connect large language models (LLMs) to tools and systems that can perform actions, such as scheduling an appointment in a calendar or making a phone call. Put an AI model and a harness together, and you get an AI agent.

DeepSeek's aptly named Harness is an open-source harness based around the idea that "everything is a plugin." A plugin is a piece of software that's added on to an existing program to give it new functionality, without altering the original.

Accordingly, Harness' new Creator Mode allows users to enter text prompts in order to generate new plugins. In a demonstration video, DeepSeek showcased examples of AI-generated plugins such as digital sticky note wall, a poster design tool, and a Minecraft-like video game.

DeepSeek has published some of the prompts used in the demonstration, offering them in both English and Chinese so users can try them out. However, DeepSeek noted that "some plugins were refined through several rounds of conversation, so a single prompt may not reproduce exactly what you see in the video."
