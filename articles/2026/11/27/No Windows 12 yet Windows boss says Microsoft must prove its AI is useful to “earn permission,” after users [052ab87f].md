# No Windows 12 yet: Windows boss says Microsoft must prove its AI is useful to “earn permission,” after users pushed back on Copilot in Windows 11

Windows Latest · Abhijith M B · 2026-11-27

Microsoft has no Windows 12 release date to share, as Windows chief Pavan Davuluri says the company’s priority right now is making Windows 11 faster and more reliable, and proving that its AI features deserve a place in the OS.
Yes, we know a lot of you still can’t stand Windows 11. But Davuluri says the OS now has more than a billion users, which, if you think about it, is about one in eight people on the planet. If an OS used at that scale gets faster and breaks less often, it’s a win for a big chunk of the world, whether you’re fond of Microsoft or not.
Pavan Davuluri says Microsoft must “earn permission” before building the next Windows
Asked at Microsoft’s Ignite conference earlier this month when Windows 12 might arrive, Davuluri told Axios that Microsoft is focused on “the quality, the craft, the fundamentals, the performance, the reliability” of Windows 11. The Windows EVP neither ruled out Windows 12 nor gave a timeline. Back in May, he’d already said that Microsoft’s then big announcement wouldn’t be Windows 12.
According to Davuluri, Microsoft also has to build the technology for future AI apps and show that people find those capabilities useful. Only then does the company “earn permission” to move on to what’s next.
He still expects local AI models with 10 billion to 20 billion parameters to bring more capable features to PCs, where local AI is already catching on with developers, creators and knowledge workers.
Bob O’Donnell, chief analyst at Technalysis Research, told Axios that “this stuff should be working and it should be working solidly, securely all the time,” adding, “we’re still not quite there yet.” Businesses that only recently moved from Windows 10 wouldn’t welcome another big upgrade, he said.
Windows 11’s bugs and Copilot push forced Microsoft to rethink its priorities
Windows 11 launched on October 5, 2021, and it took away things people used every day in Windows 10, like Live Tiles and the ability to move the taskbar. Its hardware requirements, including TPM 2.0 and Secure Boot, also left many perfectly working Windows 10 PCs without an official upgrade.
Then came the infamous bugs. In 2025, we counted 20 major Windows 11 update problems, from broken Remote Desktop to boot failures, all while Microsoft was busy adding Copilot to Notepad, Paint, and File Explorer.
When Davuluri posted in November 2025 that Windows is “evolving into an agentic OS,” the replies were so hostile that he locked them. “Microslop” soon became the internet’s favourite name for Windows 11, and many openly talked about leaving for macOS or Linux, and unfortunately for Microsoft, many did.
By late January 2026, Microsoft admitted Windows 11 had gone off track and promised to fix it.
Microsoft is fixing Windows 11 first, and 2027 could decide whether people want Windows 12
The landmark announcement came on March 20, when Davuluri laid out a detailed plan to “raise the bar on Windows 11 quality,” with fewer Copilot entry points in Snipping Tool, Photos, Widgets and Notepad, and fewer forced updates.
The truth is that Microsoft has delivered a lot of it. The taskbar can move to the top, left, or right again after five years, and Microsoft keeps replacing legacy UI with WinUI 3.
My favourite is their work to make 8GB RAM PCs usable. Windows 11 26H2 now keeps up to 2GB more of your apps in memory on 8GB PCs. At Ignite, Microsoft also said Microsoft 365 uses 360MB less RAM, while Defender, Purview and OneDrive together free up over half a gigabyte.
At a time when OEMs, including ASUS, are forced to sell 8GB PCs, Windows 11’s memory optimization becomes all the more necessary.
Whenever I am on social media, be it X, Reddit, or even Instagram, I notice how people react to anything related to Windows 11, including new features. From what I see, the insane hatred that the OS rightfully garnered has gone down considerably this year. Most people I see are now neutral, some still hate it, and a few of us like it, but it’s a far cry from 2025, when the whole world was against Windows 11, and for the right reasons.
So, is Windows 12 in development? Microsoft hasn’t said. What we know is that the company is reportedly preparing Windows 11 27H2 as a full OS upgrade for 2027, which may mean no Windows 12 next year, just a new wallpaper replacing Bloom. Microsoft hasn’t confirmed the branding, and O’Donnell thinks Windows 12 will come once Microsoft can build these AI pieces into the interface, saying, “maybe that’s when you start to see Windows 12.”
In my opinion, Microsoft should do everything they can to make 2027 the year people start liking Windows 11. Only then should they tease Windows 12, and if it launches a year later, it should be ready from the day they announce it, unlike Windows 11, which took five years to get back its movable taskbar.
Microsoft knows how to do this. According to a 1996 case study by Kent Sullivan of the Windows 95 UI team, Windows 95’s interface went through 64 phases of lab testing with 560 people, and “literally no detail of the initial UI design” survived unchanged.
You’d be surprised to know the insane efforts that went into creating the Windows 95 Start menu. I’d love to see Microsoft do that kind of homework for Windows 12, instead of finding new places for a Copilot button.
