# Microsoft and Intel deepen collaboration to deliver differentiated Azure infrastructure

Microsoft Source · sbaynes · 2026-11-18

Microsoft and Intel deepen collaboration to deliver differentiated Azure infrastructure
The two companies are working together to develop differentiated capabilities in Azure and system-level optimizations, tailoring infrastructure to the performance, efficiency, scalability and security requirements of cloud and AI
REDMOND, Wash., and SANTA CLARA, Calif. – November 17, 2026 — Microsoft (Nasdaq: MSFT) and Intel (Nasdaq: INTC) today announced an expansion of their decades-long collaboration under a long-term agreement to advance select areas of Azure infrastructure for growing cloud and AI demand. Microsoft is the first company to announce use of Intel Foundry’s EMIB™ (Embedded Multi-die Interconnect Bridge) advanced packaging technology for Azure first-party silicon. Bringing together Intel silicon and EMIB capabilities with Microsoft’s cloud engineering, the agreement confirms multi-year Intel® Xeon® supply capacity – including instances of next generation server CPUs, codenamed Diamond Rapids – and expands collaboration across the Azure roadmap and Intel-based Azure hardware systems. 
Microsoft will also collaborate with Intel on Intel Xeon with Compute Express Link (CXL) to drive greater memory efficiency and system-level innovation across Azure, as well as Intel QuickAssist (Intel QAT) and confidential computing. This work further advances existing memory and database performance, including:
- Up to 2.3x greater performance1 and memory flexibility for demanding workloads in Azure M-series v4 virtual machines with CXL memory and Intel Flat Memory Mode in Xeon 6 processors.
- Improved performance and reliability with up to 2.5x faster SQL backups2 on Azure through the first Intel QuickAssist Technology (QAT) enabled virtual machines in the cloud.
- Virtual machine memory and CPU register state encryption as confidential VMs move between hosts through Intel Trust Domain Extensions (Intel TDX).
Together, these investments are designed to provide Microsoft customers a more predictable, scalable and resilient infrastructure foundation, with compute optimized for demanding cloud and AI workloads, more efficient memory and stronger capabilities for protecting sensitive workloads.
“Our customers need infrastructure built around the workloads that matter to them. Our longstanding collaboration with Intel brings together advanced packaging, custom compute, memory and security capabilities to support Azure compute and continued innovation across Azure. Together, we are connecting silicon and systems engineering to move the industry forward and meet the growing demand for Cloud + AI computing for our customers,” said Saurabh Dighe, CVP, Azure System & Architecture, Microsoft. 
“Microsoft and Intel share a clear view of where AI infrastructure is headed–increasingly complex systems designed through the co-optimization of silicon, packaging, compute memory and software,” said Naga Chandrasekaran, EVP, Chief Technology and Operations Officer and General Manager of Intel Foundry. “Through use of our advanced packaging capabilities with EMIB to scale future generations of Azure infrastructure, Intel and Microsoft can combine the flexibility of heterogeneous integration with the manufacturing scale required for the AI era—giving customers new levels of performance and economics when interacting with Azure.”
