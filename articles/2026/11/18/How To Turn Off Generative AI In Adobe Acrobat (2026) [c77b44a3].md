# How To Turn Off Generative AI In Adobe Acrobat (2026)

The Droid Guy · The Droid Guy · 2026-11-18

How To Turn Off Generative AI In Adobe Acrobat (2026)
Adobe Acrobat now ships with generative AI features such as AI Assistant switched on by default.
If you would rather not see them, Acrobat has one checkbox in its Preferences that turns them off.
This guide gives the exact path on Windows, Mac and the mobile app, and says what Adobe does and does not state about the setting.
Quick answer
On desktop, clear the Enable generative AI features checkbox and select OK.
Turn off generative AI in Acrobat on Windows
- Close all open documents in Acrobat.
- Open the Menu, then choose Preferences.
- Select Generative AI in the list of categories.
- Clear the Enable generative AI features checkbox.
- Select OK to save the change.
Adobe asks you to close open documents first, so do that before you open Preferences.
Turn off generative AI in Acrobat on Mac
- Close all open documents in Acrobat.
- Choose View > Preferences > Generative AI.
- Clear the Enable generative AI features checkbox.
- Select OK.
That is the menu path Adobe lists for macOS, which differs from the Windows route.
If your Mac build puts Preferences somewhere else, look for the same Generative AI category inside Preferences.
Turn off generative AI in the Acrobat mobile app
- Open Acrobat and tap the profile icon in the top-right corner.
- Choose Preferences.
- Switch off Enable generative AI features in Acrobat.
Adobe’s mobile page lists these steps for Android and says the switch hides AI Assistant, Generative summary and Generate podcasts.
What the setting controls
Adobe’s desktop page does not list every feature that disappears.
It does say that turning the setting on enables AI Assistant and smart suggestions across Acrobat.
Treat the desktop list as the minimum, since Adobe does not give a full inventory.
How to turn it back on
Adobe does not publish separate steps for turning the features back on.
The same Generative AI preferences page is the place to look, and the checkbox is the control that enables them.
On mobile, return to the same Preferences screen and switch the toggle on.
Why you may not see AI features at all
Adobe lists requirements that must be met before generative AI features work.
Adobe also says support for older versions ended on June 1, 2026.
If the features never appeared on your copy, one of these requirements is a likely reason.
File limits Adobe states for the AI features
Adobe says AI features work with files under 100 MB and up to 600 pages.
Files that are password protected, carry usage restrictions or are PDF Portfolios are not supported.
Server settings can change the size and page limits.
If you manage Acrobat for a team
Adobe says generative AI is enabled by default and that admins can revoke access for teams or organizations.
Individual users can turn the features off themselves with the Preferences checkbox described above.
For the Acrobat extension in Chrome and Edge, Adobe documents a policy named DisableGenAI that admins set to true to turn off generative AI features.
Adobe says admins apply it through Group Policy so it covers all users in the organization.
Plans and usage limits Adobe states
AI Assistant needs a plan that includes it, such as AI Assistant for Acrobat or Acrobat Studio, according to Adobe’s usage policy.
Adobe also says plans may include a limited number of free Requests, after which you need an Acrobat AI plan.
A Request is a prompt, a selected suggested prompt or an AI task, and only Requests that produce a Response count toward the limit.
Adobe says Requests that fail because of technical issues do not count.
Adobe says limits apply per user by minute, hour and day, and going over them returns an HTTP 429 error.
Summary and question Requests cannot be applied to or combined with Creative Cloud generative credits, and Adobe says it may change usage limits at any time.
Adobe adds that it may add generative credit consumption for Acrobat later, so these figures can change.
How your documents are handled
Adobe’s usage policy states that generative AI features involve cloud processing of documents.
That is one reason some people choose to switch the features off on a work or personal machine.
