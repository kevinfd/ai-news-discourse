# DeepSeek drops separate fees for model-triggered web searches

TechNode · TechNode Feed · 2026-11-18

DeepSeek has removed separate charges for web searches, image searches and webpage fetching performed through its models’ built-in server-side tools. Developers now pay for the model tokens used during those interactions, including the material retrieved and processed. The change took effect on November 18.
The tools let developers build applications that search for current information and read webpages as part of a model conversation. The pricing change applies when the model invokes those tools. Applications that call the standalone Search and Fetch APIs directly continue to pay the corresponding request fees. [DeepSeek, in Chinese]
