# I’ve tested Ubuntu 27.04 ahead of its April release – and it will wow you

ZDNet · Jack Wallen · 2026-11-18

ZDNET’s key takeaways
- Ubuntu 27.04 is due out in April 2027.
- The new release includes upgrades to GNOME, the kernel, and more.
- Users will be able to upgrade from 26.10 or install it as a new release.
Ubuntu 27.04, Tenacious T-Rex, is set for an April 22, 2027 release. Although that seems a long way off, it’s sooner than you think. As is implied by the release number, 27.04 is not an LTS release, so it only receives support for nine months (until January 2028). The good news is that you can migrate from 27.04 to 27.10, and then to the LTS release, 28.04. The entire upgrade path ensures that you don’t have to miss a single release.
But what’s coming in Ubuntu 27.04? Given that it’s an interim release, you’re probably assuming that there’ll be nothing exciting to be found. Although there won’t be any game-changing additions, there will be plenty of refinements and bug fixes.

More from ZDNET
GNOME 52
This is probably the biggest addition to the next release of Ubuntu. And although you won’t find any major changes in GNOME, there are some important ones. First off, there will be editable quick settings, which allow for customizing, adding, removing, and rearranging toggles and widgets. GNOME 52 will also enjoy a revamped calendar popover, which streamlines the feature to focus primarily on events, time, and weather.

There will also be several improvements to window management, such as a spatial overview and a mosaic/tiling system for auto-resizing and organizing windows, a refined full-screen Alt+Tab app switcher, which will be capable of grouping older windows by application while showing newer ones individually, and finally, the ability to remember window sizing, placement, and workspace.
Desktop search is also getting a bit of polish by way of a redesigned popover and an improved results overlay that includes file previews, multiple actions, and search filters. And, as usual, there will be plenty of bug fixes and performance enhancements. The bump in speed is noticeable, too, in my testing.
Kernel and core technology changes
Ubuntu 27.04 will ship with the Linux 7.6 kernel, which includes better VRAM management for gaming and expanded support for modern hardware, such as early enablement for AMD Zen 6, stable support for Intel Xe3P, mainline boot capabilities for Apple M3 Pro/Max/Ultra, and initial support for the 2026 Steam Controller.
There will also be performance gains for both the Btrfs and Ext4 file systems, which (along with the improvements in GNOME 52) will make Ubuntu 27.04 one of the best-performing releases in some time.

Other core changes include:
- More Rust support for PowerPC architecture within the latest kernel.
- Updated releases for GCC, Python, and the Mesa graphics stack (26.3).
- Improved integration between new desktop AI tools and workflow enhancements.
One thing that surprised me is that Myna (Ubuntu’s AI dictation tool) has yet to find its way into the Ubuntu ISO as a default app. As with Ubuntu 26.10, you can install it, but you have to first add the necessary repository with:
sudo add-apt-repository ppa:canonical-desktop-team/myna
With the repository added, you can install it with:
sudo apt updatesudo apt install myna-config
Once installed, you can use it as expected.
As of right now, that’s all we know about Tenacious T-Rex.
It’s so early in the release cycle that it still uses the default 26.10 wallpaper, but there will be more information soon. I will say this: I’ve come to count on Ubuntu’s latest releases to be an improvement over the previous iterations, and from what I’ve seen so far in my testing, 27.04 will not disappoint. It may not knock you back to prehistoric times, but Tenacious T-Rex will wow you with its performance and polished looks.

It’s been a very long time since Canonical had a disappointing release, and 27.04 will keep up that trend.
What’s the release schedule?
The release schedule for Ubuntu 27.04 looks like this:
- Feature Freeze / Debian Import Freeze: Feb. 25, 2027
- User Interface Freeze: March 18, 2027
- Kernel Feature Freeze: March 25, 2027
- Beta Release: April 1, 2027
- Final Release: April 22, 2027
To find out more, check out the official Ubuntu 27.04 release notes.
