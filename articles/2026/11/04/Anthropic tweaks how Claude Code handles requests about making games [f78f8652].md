# Anthropic tweaks how Claude Code handles requests about making games.

The Verge · Jay Peters · 2026-11-04

Reverse-engineered games: All the news on video game decomps, recomps, VR and web and 3D ports
See all Stories
After clamping down on AI video game clones amid the bigger influx of reverse-engineered games, the company is adjusting its approach to try and discourage straight-up copies:
We’d added a short rule to the Opus 5.5 prompt to steer Claude away from recreating specific existing games, but it was also kicking in when you referenced one just to describe the mechanics you wanted.
We’ve updated that rule in 2.1.317. You can name a game to describe what you want and Claude should now build an original game in that genre. If you ask for a copy of the original, it’ll offer to build something similar instead.
