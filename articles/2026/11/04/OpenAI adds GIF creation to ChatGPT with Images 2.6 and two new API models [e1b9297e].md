# OpenAI adds GIF creation to ChatGPT with Images 2.6 and two new API models

RuntimeWire · ryanmerket · 2026-11-04

OpenAI launches ChatGPT Images 2.6 with GIFs, reference images and faster API models
The November 4th release brings GIFs, reusable reference images and editable frames to ChatGPT and Codex, plus two API models with 50% faster image generation and Flare output in as little as six seconds.
By Ryan Merket · Published · Updated
Primary source: openai.com
Why it matters
Images are already one of ChatGPT's highest-volume uses, and OpenAI says that volume reached 4 billion images per week across ChatGPT, Codex and the API. GIFs, saved references and frame editing push that traffic from one-off generation toward repeatable creative work, where consistency and export formats decide whether output can be used in campaigns, products and apps. For developers, Flare and Sunburst turn speed and edit consistency into explicit API choices, giving OpenAI a way to serve fast draft generation and higher-value production work from the same image stack.
OpenAI launched ChatGPT Images 2.6 on November 4th, adding GIF creation and reusable reference images to ChatGPT and Codex and releasing two related models for developers through its API. OpenAI said Images 2.6 is available globally across all subscription tiers on desktop, mobile and web. The release also gives developers GPT-Image-2.6 Flare for faster generation and GPT-Image-2.6 Sunburst for higher-quality output and consistency across edits.…
