# Google's AI Overviews Botched My Own Work. Here Are 8 Ways I Get Around Them

PCMag · Lance Whitney · 2026-11-04

Earlier this year, I was using Google’s search engine to conduct research for an article. As usual, the AI Overview was the first item that popped up. Relying on its answers is always tempting to save time, but as I was reading the AI-generated results, a couple of sentences didn’t sound right to me. Looking at the source, I discovered that it was one of my own articles. Worried that I had gotten the facts wrong, I read my article only to learn that it was correct, and the AI Overview had misinterpreted my writing.
Though I’m always dubious about the accuracy of AI-generated info, this incident taught me a helpful lesson, and one that I think everyone should keep in mind. AI can’t be trusted.
Yes, AIs like Google Gemini, ChatGPT, Microsoft Copilot, and Claude can be helpful. Whether you’re performing research, seeking an answer to a simple question, or looking to generate content, AIs aim to serve up the information you want. But AI can make mistakes. And that’s especially true with Google’s AI Overviews.
The severity of the problem depends on your request to the AI. If you ask it to generate content, such as an email, letter, poem, limerick, image, or video, you can easily see if the result matches what you want. If not, just ask it to try again. But if you’re looking for factual information on a specific topic, that’s where you have to be careful.
But what good is the overview if you can’t fully rely on it? With all of this in mind, here are several options to consider the next time you’re searching for information online.
1. Check the Sources
If and when you use Google’s AI Overviews or AI Mode, make sure you check the sources that Google uses to generate the summary, which appear to the right of the overview as well as in the context of the overview, typically after each paragraph or section. On the right, click Show all to see all sources. There, click the link for a specific source to visit the website where you can read and review the original information. In the overview, hover over any link to preview the information, then select it to visit the site.
2. Choose Your Preferred Sources
Whether you run a regular search or use AI, Google lets you choose your preferred news and website sources. With this option, you can add trusted sources to improve the accuracy and reliability of the AI-generated summary.
To set this up, browse to the Source preferences page and make sure you’re signed in with your Google account. In the field for Search by name or website, start typing the name or website address of a site you’d like to use as a preferred source. When the site appears in the results, check the checkbox to add it. Google will then attempt to give preference to your chosen sites when you run a search. To remove a source, just uncheck its checkbox.
3. Disable the AI Overview
Want to see only regular search results without the AI summary? Remove it by adding -ai to your search term, and the overview won’t appear. This works with Google’s search site on both desktop and mobile devices, as well as in the Google mobile app. (You can actually put anything after the minus sign, like -pcmag, to remove overviews, but -ai is easy to remember.)
4. Use an Extension to Hide the Overview
Instead of adding -ai to your search term, you can automatically hide the overview for every search you run with an extension. For Chrome and Edge, try Hide AI Overviews or Bye Bye, Google AI. For Firefox, check out AI Overview Hider for Google or Remove AI Overview.
5. Switch to Web Results
Google provides a search filter that lets you view traditional results. If an AI Overview pops up and you’d rather view the actual sources, click Web under the search bar. If you don’t see it, click the More button and then select Web from the menu. After you select it, the AI Overview panel will be removed from search results.
6. Use Google's Web Guide
Google offers a tool called Web Guide, which you can enable for your searches. Available as a Google Labs experiment, Web Guide is similar to using the Web filter, but it automatically applies to every search once you turn it on. To try this, head to the Web Guide experiment page and make sure you’re signed in with your Google account. Then just turn on the switch. Now every search you run will show you the Web Guide result at the top. From there, you can always jump to a classic search to see the traditional results.
7. Add a Shortcut as Your Search Engine
Chrome, Edge, and Firefox all let you add custom shortcuts as search engines. With this capability, you can set up a Google search URL and append a specific string to it to bypass the AI Overview and show you just plain web results.
In Chrome, go to Settings > Search Engine > Manage search engines and site search. Go to the Site search section and click Add. In the pop-up window, type a name such as "Google No AI." Enter a shortcut like @noai. In the URL field, type the following string: https://www.google.com/search?q=%s&udm=14. Click Save. You’ll see the new shortcut in the Site Search section. If you want this to replace a Google AI search as your default, click the three-dot icon and select Make default.
In Edge, go to Settings > Privacy, search, and services > Search and connected experiences > Address bar and search > Search engines. Click the Add search engine button. In the pop-up window, type the same names and strings as in Chrome. Then click Add. To make it the default, click the three-dot ellipsis icon next to your new entry and select Make default.
In Firefox, head to Settings > Search. Click Add Search Engine. In the pop-up window, add the same names and strings. Click Add Engine. To make it the default, drag its entry to the top of the list.
8. Use a Different Search Engine.
Though Google’s search engine may be the most popular, it’s certainly not the only game in town. Why not try a different search engine without AI to see how it compares with Google? Some good candidates include DuckDuckGo (in No AI mode), Dogpile, Metacrawler, Mojeek, and Startpage.
