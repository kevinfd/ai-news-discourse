# Z.ai's GLM-5.4 aims to match models up to four times its size by running 28 layers twice

VentureBeat · 2026-11-24

GLM-5.4 is Z.ai's first flagship built on a Loop Transformer architecture, which reuses the same layers more than once instead of stacking new ones, so the model gets more depth and more computation per token without adding parameters.
