# Anthropic lets users install Claude artifacts as Mac and Windows desktop apps

FoneArena · Tamil G · 2026-11-24

Anthropic has introduced an option to install Claude artifacts as desktop apps on Mac and Windows. The feature, called Install as app, is rolling out in beta through the Claude desktop application across all plans.
Claude artifacts as desktop apps
Installed artifacts get their own desktop icon and open in a separate window instead of running inside Claude. Users can also share installed apps with others and control their permissions before allowing them to interact with the computer.
Each installed app can use Claude and the user’s connectors. Apps update automatically when the underlying artifact is edited, and requests made by an app to Claude count toward the user’s plan usage limits.
Artifacts were initially introduced as shareable outputs, such as charts and webpages. Users now also create tools for everyday work, including meeting preparation pages that retrieve information from calendars and email, and order trackers that monitor shipments scheduled for the day.
Installed apps can also send notifications and add items to the macOS menu bar or Windows system tray.
Anthropic has shared examples of desktop apps created by its employees:
- Linnet: A layered image editor.
- Phosphor: A file manager with an interface inspired by a movie set.
- Sift: An app that creates folder rules and uses Claude to organize files.
- Tern: A terminal with Claude assistance for explanations and guidance.
- Vitals: A menu bar and system tray app for monitoring computer performance.
Anthropic has also shared additional demo apps created by one of its engineers.
Permissions for installed apps
Claude offers three permission levels for installed artifacts:
- Default: Apps can only access capabilities available to them in a browser.
- App permissions: Apps can request access to features controlled by Claude, including always-on-top windows, global keyboard shortcuts and notifications.
- Full computer access: Apps can request permission to run programs and read, modify or delete files without asking for approval each time.
Permissions apply only to the current version of an app. Claude requests permission again whenever the app is updated, including changes made by the user. However, content loaded from another website can change without another permission request.
Full computer access is available only for apps created by the user or, on Team and Enterprise plans, by people within the same organization. Anthropic does not review apps before installation, so users should grant full access only to apps they trust.
Team and Enterprise administrators can control app permissions and full computer access across their organizations.
How to install Claude artifacts as desktop apps
Users can describe an app they want to create in Claude, build and test it as an artifact, and select the Install as app option. The process does not require packaging or signing the app. Installed apps use the user’s existing Claude account, so a separate API key or login is not required.
To install an existing artifact:
- Update Claude for Mac or Windows.
- Open an artifact you use regularly.
- Select Install as app from the Share menu.
The feature is rolling out in beta across all plans, with the following availability details:
- Team: Enabled by default, with full computer access disabled.
- Enterprise: Disabled by default until an administrator enables it.
- Not supported: HIPAA-ready organizations and hybrid deployments cannot use the feature.
Users must be online and signed in to Claude to open installed apps. Some artifacts, including Claude Docs, Slides and Sheets, cannot be installed as desktop apps.
