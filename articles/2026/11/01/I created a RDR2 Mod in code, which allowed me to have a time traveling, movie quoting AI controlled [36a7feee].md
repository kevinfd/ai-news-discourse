# I created a RDR2 Mod in code, which allowed me to have a time traveling, movie quoting AI controlled companion. Claude controls in real time

YouTube · bagomojo · 2026-11-01

I thought it would be fun to have an AI-controlled companion who was an IT nerd stuck in the past. It was scripted in code. I was originally basing it on myself, so I cloned my voice at ElevenLabs and used that API for text-to-speech. It uses Sonnet for default movement or dialogue, bringing in Opus for gunfights and campfires, where he will tell stories. In the initial release, I have set up profiles so you can create your own companion. The GitHub is https://github.com/Bagomojo/rdr2-companion The trailer was made from real in-gameplay, edited in Claude Code.
