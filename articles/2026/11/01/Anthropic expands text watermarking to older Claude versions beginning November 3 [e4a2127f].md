# Anthropic expands text watermarking to older Claude versions beginning November 3

Mashable · Phil Clark · 2026-11-01

Anthropic expands text watermarking to older Claude versions beginning November 3
As we first reported in early August, Anthropic has bowed to demands from EU legislators that AI-generated text carry a hidden watermark, to help eventually distinguish between human- and AI-generated content.
The initial watermark rollout only applied to the latest and greatest versions of Claude, but on Friday Anthropic alerted its users that an expansion of the watermark would soon roll out to Claude Mythos 5, Claude Opus 4.7, Claude Opus 4.6 and Claude Sonnet 4.6, starting on November 3.
According to the AI giant, it will be the same watermarking technology already in use in Opus 5.5, based on "an imperceptible pattern in word choice" that won't change the accuracy or readability of its output, or contain any identifying information about the user or organization working with Claude.
