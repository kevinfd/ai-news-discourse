# I made a first-grade kanji learning app with ChatGPT dots! Fun study with quizzes and gacha

note · Makari｜AIイラスト · 2026-11-01

I made a first-grade kanji learning app with ChatGPT dots! Fun study with quizzes and gacha
Hello, this is Makari.
Previously, I made an addition and subtraction practice app for my first-grade son, and he has been using it more consistently than I expected...!
Since it worked out quite well, this time I made an app to learn first-grade kanji in a fun way😊
It is an app that can be played from a smartphone or computer browser.
This time, I had the app created using ChatGPT's "dots."
It was created as a ChatGPT Site.
I like dots because it understands my intentions and proceeds with the work nicely just by giving instructions via spoken language from my smartphone😊
This time, I will introduce the simple steps to create the app and the features of the completed app💡
Steps to create the app
First, I roughly tell dots what kind of app I want to create.
Even without deciding on the fine specifications, it will first turn it into an app form.
After that, while actually touching the app it created,
"I want you to do this more"
"This part isn't working well"
and other things I noticed, I tell it via chat to have it fixed.
Also, a convenient thing about dots is that it continues the requested work even if you close your smartphone or computer.
It is also a nice point that once I give the instructions, I can do other work in the meantime.
This time, I mainly requested the following content.
Being able to use it as a dictionary during homework and 
being able to learn happily through quizzes and gacha were the things I kept in mind while having it made😊
The finished app is here
This is the app I finished✨
You can open it from either a smartphone or a computer◎
The main features are the following four.
1. Kanji Quiz
2. Gacha
3. Kanji Dictionary
4. Character Encyclopedia
I will introduce each one!
......................................
1. Kanji Quiz
When you press "5 questions in order," kanji problems will be presented.
Enter the reading and press "Answer" to get coins!
Once you solve 5 questions and save up coins, you will be able to pull the gacha◎
......................................
2. Gacha
This is the gacha screen.
It really looks like a gacha😊
The characters that appear were also created by dots.
They are quite cute, aren't they...!✨
When you save up 5 coins, you can pull the gacha, so
it seems like it will be fun to keep studying.
......................................
3. Kanji Dictionary
In the "Kanji Dictionary," the kanji learned in the first grade of elementary school are lined up.
I had them arranged in the order of the "Kanji Skills" book that children use at school.
This way, it seems easy to use for daily homework too◎
When you select a kanji, you can check its stroke order or
look up its on-yomi and kun-yomi readings.
I made it so that it can be used not only for quizzes but also when you want to look up kanji💡
......................
4. Character Encyclopedia
In the "Character Encyclopedia," you can check the characters you've obtained from the gacha🐶
This time, we had 30 different types of characters prepared in total.
There is also the fun of collecting them to see what kind of characters will appear😊
Conclusion
This time, I used ChatGPT's dots to create a kanji learning app for first graders.
I feel it's amazing that you can build something like this just by telling the chat what you want to do, even without programming knowledge.
There are still parts I want to fix, so I plan to improve it little by little while actually using it😊
I hope this article will be of some help to those who want to try making an app.
Thank you for reading until the end🌿
